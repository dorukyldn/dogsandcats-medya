# dogsandcats-medya

Public media for scheduled posts of the "Tesla, Wolfie & the Paw Gang" cartoon channel
(https://youtube.com/@dorukyldon). Metricool fetches the video and thumbnail files from here at publish time.

- Folder per episode: `<YYYY-MM-DD>_<no>/` → `episode.mp4`, `thumbnail.jpg`, `short_<n>.mp4`
- Source project (private): `dorukyldn/dogsandcats`
- Files stay under 100 MB (raw.githubusercontent.com limit).
